📘 Simple Grade Calculator
Author: Lavanya Chandran
Live Demo: https://lavanyacs.github.io/gradecalculator_project/

📝 Project Description
This is a Simple Grade Calculator built using HTML, CSS, and JavaScript. It allows users to input marks for five subjects, calculates the total and average, and determines a grade based on the average score using conditional statements.

🎯 Features
Collects user input via prompt() for five subjects

Calculates total and average marks

Assigns grade based on the average:

A+ for average ≥ 90

A for 80–89

B for 70–79

C for 60–69

D for 50–59

F for < 50

Validates inputs to ensure marks are between 0 and 100

Displays the output using alert() and console.log()
